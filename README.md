# MemoMark · 时光记

MemoMark 为 Apple Photos 中的照片留下年龄、纪念时长和自己的文字。照片在设备本地处理，保存新的记忆照片，保留原始照片。

## 支持

使用中遇到问题，或有想告诉我们的建议，请联系 [serydoo@gmail.com](mailto:serydoo@gmail.com)。

描述问题时，可以提供 App 版本、设备型号、系统版本、操作步骤，以及屏幕上出现的提示。无需发送原始照片、家庭信息、Apple 账户密码或付款资料。

购买、恢复购买与订阅管理由 Apple 系统提供。请勿将 Apple 账户密码发送给开发者。

## Support

For help or feedback, email [serydoo@gmail.com](mailto:serydoo@gmail.com).

Please include the app version, device model, OS version, steps to reproduce, and any error message. You do not need to share original photos, family information, Apple Account passwords, or payment details.

MemoMark processes selected photos locally and saves a new output while preserving the originals. This repository contains public support information and the privacy policy.
